项目来源与背景

传承优秀的开源生态，打造丝滑的 macOS 原生工作流体验

[上游核心] GPT-SoVITS 与 MamboTTS 原版

本项目源自开源语音合成项目 MamboTTS 与 GPT-SoVITS 推理内核。原版主要针对 Windows 平台及 NVIDIA CUDA 显卡环境设计，在 macOS 系统上往往面临依赖缺失、环境冲突、编译困难以及启动繁琐等门槛。

[本 Fork 特色] 针对 Mac 与达芬奇的深度重构

本工程为针对 macOS (特别是 Apple Silicon M 系列芯片) 深度适配的开源独立分支。重构了底层硬件加速通道与剪辑交互层，彻底摆脱外部复杂依赖，让创作者专注于视频生产力本身。

[核心改进清单]

  • Apple Silicon MPS 原生加速：底层采用 PyTorch Metal Performance Shaders，充分利用 M 系列统一内存架构，无需昂贵的独立 GPU。
  • 达芬奇 (DaVinci Resolve) 官方脚本原生接入：基于 Fusion Scripting API 打造可视化界面，直接读取工程时间线中的字幕或 Text+ 轨道，自动合成并精确排布回时间线。
  • 音频尾部多余空白截除：消除 TTS 模型常见的 0.3~0.5s 尾部停顿，通过动态振幅分析截除静音并平滑淡出，极大提升短视频口播的紧凑度。
  • 轨道自动裁剪与对齐：支持一键将文本轨裁切至与生成音频等长，支持左对齐与右对齐切换，重叠音频自动覆盖或独立新建轨道。
  • 零配置一键安装：集成 Cloudflare R2 极速分卷分发与全链路单分片 SHA256 实时自校验机制，断点重试时自动识别并修复残缺片段，杜绝因网络中断导致的残片误判。

系统架构与运作原理

从时间线台词识别到音频注入的端到端技术链条

01

达芬奇时间线轨道扫描 (Resolve Scripting Bridge)

通过达芬奇内部脚本环境或外部 IPC 通信注入 DaVinciResolveScript 运行时，自动识别当前活跃工程与时间线，扫描字幕轨 (Subtitle) 与 Text+ 标题轨中的所有台词内容、入出点帧数（In/Out Frames）及时间码。

02

高拟真语音合成与 MPS 张量计算 (Inference Engine)

本地后台常驻的 GPT-SoVITS 引擎接收合成指令，利用 macOS MPS 硬件加速调用曼波或自定义参考音频音色模型，在毫秒级内完成文本特征提取、声学特征生成与高质量波形生成。

03

音频静音分析与尾部截除算法 (Smart Post-Processing)

程序对合成生成的 WAV 波形进行逆向振幅分析，检测有效发音的截断点，自动裁剪多余的尾部无声数据（保留 60ms 自然衰减并施加 15ms 线性淡出），防止出现爆音与不自然的空白缝隙。

04

时码换算与无损插入 (Timeline Injection & Alignment)

根据工程设定帧率（24/25/30/60 fps）精确换算音频帧长度，将音频直接写入指定音轨。若勾选自动裁剪，系统会自动将对应的文本轨道项裁剪为与音频时长一致，实现音画精准对齐。

下载与安装指引

提供压缩包直接下载与 Git 仓库两种获取方式，按需选用

方式 A：源码压缩包安装（适合无 Git 环境的普通用户，推荐）

[无需安装 Git]
  1. 下载源码压缩包： 点击下方按钮直接下载包含全部脚本与插件的源码包（约 1.2MB）：
    [立即下载 MamboTTSforMac-source.zip]
  2. 解压并打开文件夹： 解压后进入解压得到的 MamboTTSforMac 目录。
  3. 运行一键部署脚本： 双击运行 install_mac.sh（或打开终端进入该目录执行 ./install_mac.sh）。
    安装程序会自动从高速 R2 镜像拉取预编译运行时环境与模型，完成自动解压与达芬奇插件配置。
  4. 启动使用：
    • 独立客户端：双击 MamboTTS.command；
    • 达芬奇插件：打开达芬奇工程后，在顶部菜单【工作区 -> 脚本 -> Utility -> MamboTTS_Resolve】直接呼出，或双击 MamboTTS_DaVinci.command。

方式 B：Git 仓库克隆（适合开发者）

[支持便捷升级与追更]

在终端中按顺序执行以下命令：

git clone https://github.com/qwertrewqwertrewq/MamboTTSforMac.git cd MamboTTSforMac ./install_mac.sh

后续更新代码只需在目录内执行 git pull 即可。
