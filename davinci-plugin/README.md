# MamboTTS 达芬奇 (DaVinci Resolve) 一键配音插件

专门为 **达芬奇剪辑师 / 曼波短视频创作者** 打造的一键语音合成与时间线精准对齐工具。

无需在外部逐条导出导入音频，在达芬奇时间线内即可实现：**读取文字轨台词 -> 一键批量合成曼波语音 -> 自动创建音频轨 -> 正好对齐在文字正下方**！

---

## 核心特性

1. **自动识别文字轨**：
   - 支持**字幕轨 (Subtitle Tracks)**。
   - 支持**视频轨中的 Text+ / 标题片段 (Fusion Text+)**。
2. **时间线精准对齐**：
   - 提取每个文字片段的入点帧（`start_frame`），生成音频后**自动将音频的开头对齐在对应文字出现的同一帧**！
3. **独立配音素材箱与音频轨**：
   - 自动在媒体池建立 `Mambo TTS` 专属素材箱，不污染原项目。
   - 自动在时间线上新建 `MamboTTS 配音` 专用音轨（或插入指定音频轨）。
4. **语速与参数自由调节**：
   - 原生支持 0.8x ~ 1.5x 语速调节（曼波经典解说推荐 1.2x 语速）。
5. **纯原厂暗黑 UI**：
   - 基于 DaVinci Resolve 原生 `Fusion UIManager`，无需额外安装复杂的 GUI 库，界面精致、与达芬奇融为一体。

---

## 快速使用

### 1. 确保 MamboTTS 引擎处于运行状态
启动 MamboTTS（终端运行 `./run.sh` 或双击 `MamboTTS.command`），保持本地引擎在线（绿色状态）。

### 2. 在达芬奇中启动插件
1. 打开 DaVinci Resolve，进入工程的 **Edit (剪辑)** 页面。
2. 确保时间线上已有你要配音的文字（字幕轨 Subtitle，或带有文字的 Text+ 标题）。
3. 点击达芬奇顶部菜单：
   > **工作区 (Workspace)** -> **脚本 (Scripts)** -> **Utility** -> **`MamboTTS_Resolve`**
4. 插件窗口会自动列出当前时间线检测到的全部台词、时间戳及帧区间。
5. 选定语速后，点击 **「🚀 一键生成配音并插入时间线」**！
6. 稍等片刻，达芬奇时间线上即可看到生成的曼波配音音频轨！
